# Programme de parrainage

Le **programme de parrainage High Stakes** vous offre l'opportunité de gagner des points **$IBEX** supplémentaires en faisant découvrir la plateforme à de nouveaux délégateurs.

## Fonctionnement

1. **Code de parrainage unique** : Un code unique (jusqu'à 10 caractères) vous est attribué et peut être partagé directement avec de nouveaux utilisateurs ou intégré dans un lien d'inscription (`https://app.highstakes.ch/dashboard?referralCode=VOTRECODE`).
2. **Saisie lors de l'inscription** : Lors de leur inscription au programme de fidélité IBEX dans la fenêtre **Enregistrez votre wallet** sur <a href="https://app.highstakes.ch" target="_blank">app.highstakes.ch</a>, les nouveaux utilisateurs saisissent ce code dans le champ **Vous avez un code de parrainage ?** (ou utilisent le lien `?referralCode=` pour qu'il soit pré-rempli automatiquement).
3. **Seuil d'activation (500 $ USD)** : Le parrainage s'active dès que le filleul délègue au moins **500 $ USD** de jetons sur l'ensemble de nos validateurs éligibles au programme IBEX et commence à générer des points quotidiens :
   - **Bonus du filleul (`AFFILIÉ`)** : Le nouvel utilisateur bénéficie d'un **bonus de +10 %** sur ses points IBEX quotidiens pendant **30 jours**.
   - **Récompenses du parrain (`PARRAIN`)** : Le parrain reçoit :
     - **10 %** des IBEX quotidiens du filleul pendant les **30 premiers jours**,
     - **5 %** pendant les **30 jours suivants**,
     - puis **1 %** du total des IBEX quotidiens gagnés par ses filleuls, **sans limite de durée**.

Si vous envisagez de parrainer seulement quelques utilisateurs, vos gains à long terme resteront limités à moins que ces derniers ne délèguent des montants importants.
